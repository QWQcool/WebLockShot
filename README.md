# WEB锁镜 WebLockShot

给竖屏短剧创作者一台 **出可灵 / 即梦之前的免费粗剪台**。用人物、冲突、钩子拆成可播放的 6 镜动态分镜（HTML + GSAP 模板，不是成片），锁镜头和台词之后，导出两家模型可粘贴的提示词包。

粗糙是特性。这是 animatic，不是给观众看的成片。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（通常是 `http://localhost:5173`）。

```bash
npm run build
npm run preview
```

无服务端、无登录。密钥只写在浏览器 `sessionStorage`，刷新标签页需重填，不会进 Git。

## 怎么体验（主路径，约 3 分钟）

1. 默认就是 **预设模拟**，零 Token。内置故事《门缝》会直接可播。
2. 点 **播放**，看完 6 镜竖屏粗剪。
3. 点时间轴上的镜号，改这一镜的 **台词** 或 **运动模板**，再播一次。
4. 点 **复制即梦包** / **复制可灵包**（或展开「查看当前即梦包」）。文案按当前 JSON 现算，改过的台词会进去。
5. 需要的话切到 **自带 Token**：填 OpenAI 兼容的 Base URL、Key、模型名，改三个短框后 **生成粗剪**。推荐 [OpenRouter](https://openrouter.ai) 或硅基流动（浏览器 CORS 通常可用）。DeepSeek 官方端点可能被浏览器跨域拦住。

页脚会写明当前是预设还是 Token。本产品 **不代出视频**。

## 真实 vs mock

| 能力 | 状态 |
| --- | --- |
| 预设 6 镜播放、改词、换运动、重做一镜（alts）、导出 | **真实**，纯前端 |
| Token 拆镜 / 重做一镜 | **真实**（需用户密钥）；无密钥时按钮不可用 |
| 可灵 / 即梦出视频 | **不做**；只导出提示词 |
| 角色图 / 视频 | **不做**；剪影色块 |
| 提示词质量 | 模板编译，**不是**模型二次润色 |
| 支付、账号、云端存稿 | **不做** |

下一步优先（未做）：一键跳转可灵并带草稿、多集、角色图参考上传。

## 技术

Vite + React + TypeScript。舞台由 `Story` JSON 编译，GSAP 只使用镜头词典里的 `motionId`。预设数据在 `presets/hook-at-the-door/story.json`。契约见 `.cursor/skills/shot-stage/SKILL.md` 与 `PLAN.md`。
