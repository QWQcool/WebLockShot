# 界面双语（i18n）说明（CANVAS_PLAN.md §9 I1）

> 更新：2026-09-11

## 怎么用

- **画布**：顶栏右侧「🌐 中文 / EN」按钮一键切换。
- **设置面板**：`⚙️ API 设置` 顶部「0. 界面语言（Language）」区块，中/英单选。
- **默认中文**：未显式切换时行为与改造前完全一致（零回归）。
- **持久化**：`localStorage` 键 `weblockshot.language`；脏值/存储不可用一律回落中文。
- **首次推断**：仅在**没有任何存储值**时按浏览器语言推断（`en*` → 英文，其余 → 中文），
  且推断结果**不写回存储**——避免把「推断」固化成「用户选择」。

## 实现

| 文件 | 职责 |
|---|---|
| `src/i18n/strings.ts` | 中英字典 + `t(lang, key, params)` + 节点/模板标签取词（纯函数） |
| `src/i18n/language.ts` | 语言读写、脏值自愈、模块级订阅 store（Storage 注入可测） |
| `src/i18n/useLanguage.ts` | React 绑定：`useLanguage` / `useSetLanguage` / `useT`（`useSyncExternalStore`） |
| `src/i18n/__tests__/i18n.test.ts` | 键对齐 / 空值 / 漏译 / 插值 / 持久化 / 订阅回归 |

**防漏译设计**：英文是 `Record<keyof typeof ZH, string>`——少一个键就**编译不过**；测试再加一层
「键集合完全一致 + 英文不得残留中文 + 中英不得完全相同」的断言，杜绝「漏译静默回退中文」。

## 覆盖范围（诚实标注）

**已覆盖**：

- 画布顶栏（品牌、副标题、模式切换）
- 画布工具条全部按钮与 title（含语言切换、MCP 徽章、保存状态）
- 节点面板（标题 / 提示 / 每个节点标签与提示）
- 节点头部（标签、可用性徽章、Skill「填新输入」提示）
- 对话栏（placeholder / 发送 / 收起 / 展开 / 场景模板 chips）
- 画布空态诚实标注条
- 开场层（D5）全部文案
- 设置面板：语言区块 + 面板标题 + 三个 section 标题
- 运行期核心反馈：编排 busy / 结果 / 降级 / 失败 / 撤销、Skill 导入结果
- 项目操作：新建提示 / 删除确认 / 默认项目名

**尚未覆盖（后续可增量补齐，切换英文时这些位置仍显示中文）**：

- 节点内部业务控件文案（Brief 编辑器、脚本/分镜/生成/产物/交付/重绘/3D 台节点体）
- Skill 市场、记忆图谱、连接器面板、创作场景画廊、3D 运镜台的深层文案
- Skill 导入/导出与项目操作的运行期提示条（部分）
- 服务端返回的错误文案（`server/` 与领域层 reason 字符串）
- 回流看板、双工作室（sell/drama）等画布之外的界面

> 这样取舍的理由：I1 的验收口径是「画布与顶栏/设置**关键文案**」，而全量翻译会牵动上千条字符串与
> 领域层 reason（后者在纯函数模块里，改造成本高且易破坏红线）。当前实现覆盖了英文用户进入画布后的
> 全部「导航 + 入口 + 诚实标注」文案，未覆盖部分已在英文 README/指南中如实说明。
