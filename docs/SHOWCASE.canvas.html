WebLockShot · 一句话到成片工程

在浏览器里跑完的创意生产工作台：在无限画布上用一句话布置 Agent 节点， 从脚本一路做到可直接导入剪映继续剪辑的成片工程。

在线体验：https://qwqcool.github.io/WebLockShot/ 技术栈：React 19 · TypeScript 6 · Vite 8 · tldraw 5 · three.js · GSAP 形态：纯静态可部署 · 免安装 · 免 API Key 即可跑通全链路（演示引擎）

打开链接即可完整体验，不需要注册、不需要配置任何 Key：对话栏说一句话，画布上会自动长出一条 Agent 节点链路；点几下就能拿到脚本、9:16 分镜预演、逐镜出片，最后打包出一份能导入剪映的工程文件。

一、端到端链路：一句话 → 成片工程

这条链路不是流程图上的箭头，而是能在浏览器里点完的真实路径：

步骤 用户动作 系统实际做了什么
① 需求 对话栏输入一句话（或点场景模板） LLM 编排；无 Key 时自动降级为演示编排并如实标注「非真实 LLM」
② 落位 —— 按场景路由在画布上布置节点拓扑与连线（可一键整批撤销）
③ 脚本 点「生成脚本」 ScriptWriter 产出脚本 + Critic 对立面评审（含评分与修改建议）
④ 分镜 点「生成分镜」 拆成 6 镜，生成 9:16 的 GSAP 动态分镜预演（本地渲染，可播放）
⑤ 出片 点「逐镜出片」 ExecutorEngine 串行队列逐镜执行；钱包先冻结、成功核销、失败全额退款
⑥ 交付 点「打包剪映草稿」 生成三轨对齐的 draft_content.json + 完整素材 zip，真实下载

二、三个差异化能力

2.1 3D 运镜台：把「运镜」变成可预演、可复用的本地能力

同类创意画布大多止步于 2D 出图。这里内置了一套本地 3D 预演台——全程在浏览器里用 three.js 渲染， 不消耗任何积分、不依赖云端 GPU：

  • 内置 CC0 素体：Quaternius Universal Animation Library，模型内嵌 45 个真实动画片段（实测值）， 其中 8 个做成动作预设（待机 / 走路 / 慢跑 / 冲刺 / 跳舞 / 坐姿 / 跳跃 / 说话）；
  • 六套程序化场景预设：商品台 / 影棚 / 客厅 / 卧室 / 户外台阶 / 展台，一键切换；
  • 多机位 + 关键帧轨迹：机位可增删、可预览，导演视角参数可提取，关键帧驱动运镜；
  • 首/尾帧导出：直接把摆好的画面接给「视频生成」节点做单镜直出，或接给「分镜预演」出自由镜数分镜。

2.2 剪映 / CapCut 草稿 zip 一键交付

多数工具交付的是「一段 mp4」，拿到后想改就只能重做。这里交付的是可以继续剪的工程：

  • 三轨对齐：视频轨 + 旁白音轨 + 花字字幕轨，时间轴微秒级对齐；
  • 完整素材包：draft_content.json 与所用素材一起打包成 zip，解压放进剪映草稿目录即可打开；
  • 两条落盘路径：纯前端直接下载 zip；伴生服务在线时还可一键解压到本机草稿目录。

2.3 诚实标注 + 可验证工程

这一条看起来「不性感」，但它决定了这个项目能不能被信任：

  • 不伪造能力：无 Key 时标注「演示编排 · 非真实 LLM」；未实现的节点标「未实现」； 空态不摆样例数据；第三方许可限制如实告知并给出官方解决路径（且不提供任何绕过手段）。
  • 不伪造测试：15 步实机 E2E 走的是真实鼠标路径；测试环境不可用时优雅跳过并打印指引，不伪装通过。
  • 不放过线上事故：两起线上事故（子路径资源 404 白屏、许可闸门致画布消失）在本地全套测试下都是绿的 ——因为本地形态与线上不同。修复后各自补了复现线上形态的回归套件（见第五章）。

三、工程实现

3.1 分层结构

层 职责 关键模块
入口层 开场层 / 对话栏 / 场景模板 ui/canvas/CanvasOnboarding、wls-chat-dock
编排层 一句话 → 节点拓扑 场景路由 + LLM 编排（可降级演示编排）
画布层 无限画布 + 9 类节点 tldraw 5 + 自研 shapeUtils、CanvasDoc 契约、localStorage 持久化 + 多标签同步
执行层 串行队列 + 结算 director/executor、domain/wallet（两阶段事务）
能力层 脚本 / 分镜 / 出片 / 重绘 / 3D ai/（ScriptWriter + Critic）、media/（6 引擎契约）、ui/stage3d/
交付层 产物卡 + 剪映工程 export/jianyingDraft + 零依赖 zip
支撑层 本地优先 / 可选伴生服务 IndexedDB 大资产、server/（TTS / ffmpeg / sqlite / MCP）

3.2 几个值得说的工程决策

  • 本地优先：API Key 只存浏览器，画布与素材默认不离开本机；纯静态即可部署，伴生服务是可选项。
  • 钱包全站唯一收口：画布生成与带货工作台走同一条钱包管线——冻结 → 核销 / 全额退款， 含幂等结算与 30 分钟 TTL 孤儿冻结自动回收。
  • 节点连线带类型契约：非法连线会被拒绝并给出提示条，避免「连了但跑不通」。
  • 3D 资源走统一 URL 解析器：子路径部署（GitHub Pages）下不会因写死根路径而 404（这条是事故换来的，见 4.2）。
  • 零依赖伴生服务：server/ 不引第三方运行时，剪映草稿落盘 / TTS / ffmpeg 合成 / MCP 桥接全用 Node 标准库。

4.2 两起线上事故的复盘（这部分是加分项）

事故 现象 根因 修复与防回归
子路径资源 404 线上点「加人物」整页白屏 3D 模型 URL 写死根绝对路径 /models/…，在 /WebLockShot/ 子路径下 404，useGLTF 抛错且无兜底 统一 publicUrl 解析器 + 根级/局部双重 ErrorBoundary + 新增子路径部署回归套件；并做负向验收（还原错误写法 → 套件 5 项失败并复现 404）
许可闸门致画布消失 线上画布内容突然全部消失 tldraw 生产环境无 license key 时约 5 秒后停止渲染编辑器（本地 http/localhost 被豁免，所以本地永远测不出来） 加如实提示条（挂在编辑器之外，闸门后仍可见）+ 新增生产模式回归套件（HTTPS + 非回环域名复现线上形态，双向断言）

这两条的价值不在「修好了」，而在于：定位到「本地测试面与线上形态不一致」这个系统性盲区， 并把两种线上形态都纳入回归。此后同类问题在本地就会红。

五、已知边界与路线（如实写出）

工程能力也体现在敢写出自己没做什么：

项 现状
移动端 / 触摸适配 尚未适配。实测 390×844 视口下顶栏被压成 223px 高、画布容器宽 969px 溢出视口（129 个元素横向溢出），画布区基本不可用。已列入待做清单（P0）
图像生成节点 占位（未实现），界面如实标注；补齐需接入文生图 / 图生图链路
真实生成质量 默认走演示引擎（不耗积分、可离线跑通全链路）；真实出片需自备引擎 Key 或本地 ComfyUI
3D 动作预设 8 个常用动作；「挥手 / 转身」在内置动画库里无对应片段，如实替代、不伪造
画布引擎许可 tldraw 为商业许可（非开源）。当前用免费 trial，2026-12-20 到期；仓库已提交 .env.production 使任何人构建都无水印，但下游使用者需自行申请许可
多人协作 未做（单机本地优先；协作属 tldraw 付费能力）

路线（按性价比排序）：移动端适配 → 节点执行历史面板（可回看的运行日志）→ MCP 工具清单产品化 （让外部 Agent 驱动画布）→ 提示词库多来源导入。
